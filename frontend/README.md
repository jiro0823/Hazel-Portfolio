# Hazel Portfolio

A responsive portfolio site for Hazel P. Felicilda, built with React, TypeScript, Vite, Framer Motion, and Lucide icons.

## Project Structure

- `src/App.tsx` assembles the page sections.
- `src/components` contains shared UI components.
- `src/components/sections` contains each portfolio section as a separate component.
- `src/constants` contains reusable configuration such as animation props.
- `src/data/portfolio.ts` contains editable portfolio content.
- `src/assets` contains image assets used by the app.

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run preview
```

## Editing Content

Update Hazel's name, contact links, skills, projects, and timeline copy in `src/data/portfolio.ts`. Replace `src/images/hazel_pic.jpg` when a new portrait is available.
